# 말빛

뇌병변장애인을 위한 개인맞춤형 의사소통(AAC) 웹앱.
이용인이 큰 버튼을 한 번 눌러 자신의 의사를 문장과 음성으로 표현합니다.

## 주요 기능

- **표현판**: 기본 · 생활 · 활동 · 내 표현 — 한 화면 6개, 그림+글자, 누르면 즉시 음성 출력
- **문장 만들기**: 누가·언제·어디·행동·마음 단어를 이어 직접 조합, 문장 속 단어를 누르면 그 단어만 빠짐
- **상대방에게 보여주는 화면**: 확정된 문장을 화면 전체에 큰 글씨로 표시 (다시 듣기 / 잠시 기다려주세요 / 맞아요 / 수정할게요)
- **도움 요청**: 알림음 → 항상 최대 음량 → 확인 단계 없음, 일반 표현과 분리된 화면
- **이용인별 맞춤**: 프로필마다 버튼 크기·글자 크기·고대비·그림 표시·선택 후 확인·누르기 유지시간·스캔 입력·음성 설정을 따로 저장
- **오작동 방지**: 누르기 유지시간, 연속입력 방지, 선택 후 확인, 스캔 입력(스위치 = 스페이스·엔터 키, 또는 화면 탭)
- **보호 표현 잠금**: 아니요 · 싫어요 · 중단하고 싶어요 · 지금 중단해주세요 · 도와주세요 · 제가 직접 선택하겠습니다 · 혼자 있고 싶어요 · 잘못 이해하셨어요 — 어떤 화면에서도 삭제·숨김 불가
- **PWA**: 홈 화면에 설치하면 인터넷 없이도 동작

## 개인정보

- 프로필·표현·설정은 **이 기기의 브라우저에만** 저장됩니다. 서버로 전송하지 않습니다.
- 기기 간 이동은 설정 → 자료 관리 → 내보내기/가져오기(JSON 파일)로 합니다.
- 클라우드 음성을 켠 경우에만, 말할 문장이 음성 합성을 위해 Google 서버로 전송됩니다.

## 음성 엔진

| 엔진 | 기본값 | 인터넷 | 비용 | 비고 |
|---|---|---|---|---|
| 기기 내장 (Web Speech) | ✅ | 불필요 | 무료 | 모든 기능이 이것만으로 동작 |
| Google Cloud TTS | 선택 | 필요 | 월 100만 자 무료, 이후 유료 | 더 자연스러운 음성, 실패 시 자동으로 기기 내장으로 폴백 |

### 클라우드 음성 연결 방법

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 프로젝트 생성 → **Cloud Text-to-Speech API** 사용 설정
2. 사용자 인증 정보 → **API 키** 발급
3. 키 제한 설정(중요): **HTTP 리퍼러(웹사이트)** 제한에 배포 주소를 등록하고, API 제한을 Text-to-Speech로 한정
4. 앱의 설정 → 음성 → 클라우드 API 선택 → 키 붙여넣기 → 〈연결 확인〉

> 정적 웹앱 특성상 API 키가 브라우저에 저장됩니다. 반드시 리퍼러 제한 + API 제한을 걸고,
> Google Cloud 결제 알림(예산 알림)을 설정해 주세요. 기관 규모로 쓸 경우 프록시 서버 경유를 권장합니다.

## 배포 (GitHub Pages)

정적 파일만으로 구성되어 빌드가 필요 없습니다.

1. 이 저장소를 GitHub에 푸시
2. 저장소 Settings → Pages → Source: `main` 브랜치, `/ (root)` 선택
3. 몇 분 후 `https://<계정>.github.io/sjb-10/` 에서 접속

새 버전을 배포할 때는 `sw.js`의 `CACHE_VERSION`을 올려야 이용 기기에서 새 파일로 교체됩니다.

## 로컬 실행

```bash
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080` 접속. (ES 모듈을 쓰므로 파일을 직접 열지 말고 서버로 여세요.)
